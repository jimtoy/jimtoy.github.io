# jimtoy.github.io

Personal site: resume, microblog, and long-form writing. Built with [Astro](https://astro.build), deployed to GitHub Pages via GitHub Actions.

The previous Jekyll-based version is archived under `legacy-jekyll/` for content migration reference.

## Local development

No Ruby, no gems — just Node.

```
npm install
npm run dev       # local dev server with hot reload
npm run build     # static build to dist/
npm run preview   # serve the production build locally
```
